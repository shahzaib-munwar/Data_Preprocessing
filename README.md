## DATA PRE-PROCCESSING FOR TRAINING MODELS 

I ASKED GEMINI TO GENERATE A NOISY DATASET SO THAT I CAN PRACTICE DATA CLEANING.

## ABOUT DATASET
THE DATASET IS SIMPLY WITH COLUMNS AS:  STUDENT-ID, AGE, GENDER, STUDY-HOURS, STATUS

THE DATASET HAD, NEGATIVE VALUES, OUTLINER, SMALL AND UPPER CASE LETTER.

FIRST OF ALL, I CHECKED THE POSSIBLE NULL VALUES BY isnull().sum() function.

THEN I GOT THE STATISTICALY SUMMARY OF THE DATASET BY USING THE FUNCTION describe() and info funtions. 

AFTER THEN FIXED THE MISSING VALUE, CASES ISSUES AND NULL OUTLINES BY manually accesing every column with loc() funtion.
